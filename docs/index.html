Decentralized MDAO by Agent Consensus

Three asynchronous discipline agents — aerodynamics, structures, weights — search a shared 6-D aircraft design space under a publish–intersect–verify protocol. A 12-round campaign for a medium fixed-wing UAV.
Interactive timelapse
Watch the campaign run: agents publishing regions, the witness verifying, the admissible set forming and collapsing. Includes the 6-D pairwise slice matrix, the coupling belief distributions, and a scrubable timeline. Hover the map for live constraint margins.
